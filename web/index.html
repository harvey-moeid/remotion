Rasio
Pratinjau kasar; hasil akhir dirender oleh Remotion.

Kode dijalankan di GitHub Actions, jadi pakai hanya kode yang Anda percaya. Fitur ini membutuhkan kode akses.

    Wajib ada export default berupa komponen React. Opsional: export const config = {durationInFrames, fps, width, height} (bawaan 150 frame, 30 fps, ukuran mengikuti rasio). Hanya paket remotion dan react yang tersedia.

    Editor: Tab / Shift+Tab mengatur indentasi, Enter mempertahankan indentasi. Tekan Esc lalu Tab untuk keluar dari editor dengan keyboard. Error pada pengecekan memblokir render; peringatan tidak.
